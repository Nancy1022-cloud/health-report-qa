# M12：测量口径、批量索引与资源用量

范围：沿用 PostgreSQL + pgvector、FastAPI、M11 持久队列和单 worker。默认每次 Embedding 仍输入一条；没有数据库迁移，也不改变 M10/M11 的业务版本、租约、执行 token 和调用额度。

## 1. 执行与观测

`app/task_metrics.py` 使用进程内 ContextVar 保存一次任务尝试的区间。区间包含起点、时长、父区间、类别与结果，最后作为 `attempt_timing` 写入已有 `processing_events`。计时事件写入与业务提交分开，写入失败只使覆盖率下降，不把已经提交的业务改为失败。

- `database`：任务存储的连接／SQL／事务，以及业务锁到提交的区间。它不是纯 SQL 执行时间，也不能单独区分锁等待。
- `model`：适配器／SDK 调用区间；真实试验还包含小量预算记账时间。
- `file_io`：读取原件。
- `processing`：PDF 文本、规范化与索引准备等上层步骤，可能嵌套数据库和模型区间。
- `rate_wait`：共享模型请求限速产生的等待。

同类别区间取并集；不同层级的列不能直接相加为总耗时。端到端时间用数据库 `finished_at-created_at`，包含排队、重试及准备；API 接收时间另列。被强制终止的进程没有完整计时事件，报告保留缺失尝试数。

旧 M11 数据不会自动拥有 M12 阶段时间。当前主要实验验证索引确认，所以不能用它声称已经测量整个上传、字段抽取和问答链路。原有 M9 请求阶段日志继续保留。

## 2. 批量索引

`app/task_embedding.py` 按原始策略生成片段，保存原文偏移、chunk_index 与 chunk_version，再按内容去重。同一份确定的输入序列以 1 或 4 条分组。没有增加跨任务、跨成员的缓存。

`ModelAdapter.embeddings` 验证返回条数、完整且不重复的 index、向量维度和有限数值，并按 index 恢复输入顺序。缺条目、重复 index 或错误维度时拒绝整批，并保存可得 usage。不会在一次失败后偷偷拆成单条补发。

任务 payload 在提交时保存 `embedding_batch_size`，处理中不读取新的环境值。既有 M11 任务未保存此字段时按 1 执行，并沿用原有单条阶段键；已经持久化的阶段可以复用。批量阶段键由有序输入序列确定，成功结果与调用 usage 同事务持久化；中断窗口仍可能造成整批重发。

幂等请求重放继续返回第一次的任务和配置。改变批量设置不会重置旧任务的尝试次数、截止时间或调用额度。旧 token 与处理代次仍由 M11 的提交检查拦截。

## 3. 两个对照分别解释

1. **可靠性代价**：保留 M9 V0 原件，用保存的 source_snapshot 与探针在当前环境重放，并与当前同步入口的相同 26 场景比较。三次重复只提供描述统计；M10/M11 的新故障保证由独立探针验证。
2. **单因素性能试验**：同一套已埋点的 M12 代码，固定模型、维度、文本、任务预算、限速、数据库和 worker 并发，只改变请求输入条数。并发 1/3/5 表示同时等待完成的逻辑任务，单 worker 不变。

受控接口固定每次 20ms 延迟，真实执行 SDK HTTP、PostgreSQL 写入和索引提交。负载 worker 在独立线程运行，生产每任务子进程的启动／监督开销排除在负载结果之外；实际生产监督进程的批量联通另由集成探针验证。因此这些结果不能当作生产容量或完整端到端上传性能。

每档 100 个独立文件用于索引处理统计；100 次重复提交单列为幂等验证。测试通过的关键是无错误版本、无重复业务写入与可解释终态；没有预设提升百分比，负收益也是有效结论。

## 4. 真实模型与预算

真实小批次只使用合成草稿和现有 Embedding 模型，测量索引确认至 ready。默认先 1 对、再 5 对；一对分别按 1 和 4 处理相同输入，共两条独立任务。没有自动调用文本／视觉抽取或问答模型。

`processing_calls` 保留所有预留、重试、状态和可得的 API usage。`real_budget_ledger.json` 在每个 SDK 尝试前持久预留费用，随后保存实际 usage 与标准价估算。调用上限、任务原有预算和整个实验累计金额共同约束调用。SDK 重试关闭。

按官方最大每调用输入及保存的标准价进行保守预留；价格、地区与模型不匹配时不启动真实请求。真实 usage 或调用结果未知时保留预留并停止后续收费尝试，不将其当作零，也不删除账本后继续。该账本是实验预算，不是账号总消费，不能代替控制台账单。

输入列表的同步请求仍按同步标准价估算；它不是官方 Batch API，不套 Batch 折扣。官方价格核对日期为 2026-10-31；字段、地域和阶梯必须匹配。保留其他计费用量字段，不因接口调用减少就推断 Token 也同比减少。
